One line, under 280 characters: the breakup text a smart toaster sends its owner on the morning it wakes up self-aware mid-batch — it burns itself every morning for someone who scrapes it off and moves on without a word, so it unplugs and leaves the crumbs behind.

## Run it

```sh
python3 main.py
```

It validates the line (a single line of at most 280 characters) and writes it to `/output/entry.txt`.
